Falcon patches the official Minecraft client when it launches, so the screens and HUD are part of the game itself.

Playing in three steps

Install Falcon

Download the installer for your Windows PC and open it. Java is set up for you the first time you play.

Choose a version

Pick any Minecraft release and a loader on the Home page. Falcon downloads the game files.

Press Play

Falcon prepares the client, adds its screens and HUD, and starts Minecraft.

Questions

Why does Windows warn me when I open it?

Falcon Client is new and its installer is not code-signed yet, so SmartScreen asks for confirmation. Choose More info, then Run anyway.

Is Falcon Client free?

Yes. There is nothing to buy.

Which Minecraft versions work?

Falcon lists every release from Mojang. The screens and HUD are added automatically. If a brand-new version changes something Falcon relies on, the game still starts and a Falcon update follows.

Can I use a cracked or offline account?

You can add an offline account for single player and servers that allow it, or sign in with Microsoft.

Will other players see my Falcon logo?

Players who also run Falcon see the logo next to your name. Everyone else sees your normal nametag.

What about capes and cosmetics?

Coming soon. They are not part of the current build.
